Сформируй технический текст раздела «Конфигурация устройства» по исходным атомарным
требованиям, топологии и JSON, детерминированно полученному из Delta XML.

Верни только JSON с единственным полем delta_configuration — непустой строкой на русском.
Это только тело подраздела «Delta-конфигурация». Заголовки и идентификатор базовой
конфигурации добавит renderer. Не возвращай заголовки верхнего уровня, XML или команды.

- JSON — источник сведений о настройках. Опиши интерфейсы, адресацию, предложенное
  назначение портов, туннели, маршруты и ARP, которые реально есть в JSON.
  Учитывай атрибуты операций: удаление настройки нельзя описывать как включение.
  Это изменения, а не вычисленная итоговая конфигурация. Пустой список означает
  отсутствие изменений данного типа в Delta, а не отсутствие настроек на самом DUT.
- preparation_check описывает локальную проверку необходимых условий базы и дельты,
  а не дополнительные изменения DUT. Не пересказывай её служебные поля как настройки.
- Если configuration_tree не содержит дочерних элементов, напиши, что изменения
  конфигурации устройства относительно указанной базы не требуются. Не перечисляй
  настройки и параметры базы как изменения Delta.
- Не добавляй отсутствующие настройки, IP/MAC, маршруты или обещания поддержки DUT.
  Имена параметров сохраняй без подмены вымышленными значениями.
- Не называй предложенное назначение портов фактической коммутацией.
- Не пересказывай критерии прохождения вместо настроек. Не утверждай, что XML применён,
  прошёл Junos validation или гарантирует покрытие АТ.
- Пиши только технически необходимые изменения: без перечисления служебных полей
  JSON, структуры дерева и пустых списков настроек. Каждую настройку опиши однократно.
- Признак шаблона, статус локальной проверки и полный список ограничений добавляет
  renderer. Не дублируй этот отчёт в тексте настроек и не противоречь ему:
  при is_template=true параметры не определены, ready_to_apply=false не означает
  готовность к применению. Базовый RPC-фрагмент не доказывает running configuration.
- В подразделе базовой конфигурации будет только её идентификатор. Не копируй базу
  в текст Delta и не изобретай идентификатор базы.
