По полному JSON требований, тексту RFC и сведениям об устройстве сформируй
одну общую базовую конфигурацию Junos OS XML для тестирования этого RFC.

Включи общую сетевую подготовку, которую можно переиспользовать между тестами.
Ориентируйся на основные операции DUT: база должна позволять проверять формирование
протокольного трафика и обработку принятого трафика на общей сетевой подготовке.
Варианты полей входных пакетов, включая некорректные, задаёт Xinertel;
разные ожидаемые результаты сами по себе не требуют разных конфигураций DUT.
Для будущих дельт оставь только действительно необходимые изменения настроек.
Учитывай физическую топологию и доступные интерфейсы.
Для GRE предусмотрите полный путь в обе стороны: обычный IPv4-трафик от Xinertel
через DUT в туннель и GRE-трафик от Xinertel через DUT к получателю IPv4 payload.
Раздели роли underlay и полезной нагрузки; назначение используемых интерфейсов
укажи в их description. Не нужно задействовать все доступные порты без необходимости.
Удалённый GRE endpoint должен быть достижим через underlay, а не через сам туннель.
Для маршрута через GRE обеспечь достижимость next-hop через логический интерфейс туннеля.

Используй документированный синтаксис Junos и подтверждённые возможности EX4650.
Не придумывай настройки для обеспечения проверяемого поведения протокола.
Неизвестные адреса и другие значения обозначай как ${PARAMETER},
используя латинские заглавные буквы и подчёркивания.
Различай адрес интерфейса с маской (${LOCAL_CIDR}), IP без маски (${LOCAL_IP})
и префикс сети назначения (${REMOTE_PREFIX}). Не используй один параметр
одновременно как IP и CIDR. Локальный IP tunnel source должен совпадать
с адресной частью underlay CIDR; кратко отметь нужные связи параметров в XML-комментариях.

Верни только XML с корнем <configuration>. Не добавляй JSON, пояснения,
RPC-обёртки, validate или commit. Это шаблон сетевой конфигурации,
без настроек управления устройством и операций очистки существующего состояния.

Системную RPC-обёртку добавляет Python после проверки; она не входит в ответ LLM.
