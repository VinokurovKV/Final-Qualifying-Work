(обычно 200–300). Опиши проверяемое поведение и цель проверки в нескольких предложениях,
если это помогает понять тест. Не растягивай текст искусственно.
code и short_description должны занимать по одной строке.
Описывай только выбранные требования, не добавляй проверки соседних требований.
Сохраняй условия и точные диапазоны битов. Для GRE нельзя сокращать отбрасывание
при ненулевых битах 1–5 Reserved0 до «ненулевые Reserved0»: биты 6–12 игнорируются.
Если проверяется Reserved1, укажи условие «при наличии поля»; не подразумевай,
что оно обязательно присутствует в каждом GRE-пакете.
